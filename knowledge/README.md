# 本地基础知识库

助手自动从本目录的 JSON 检索与当前题目有关的条目，最多提供 3 条、共 2500 字符给模型。生成、复核和修复使用同一份题目知识；候选代码中的无关词不会改变本题检索结果。普通问答也会检索。不需要联网、额外模型或向量数据库，不改变模型权重。

输入 `/知识库`（或 `/knowledge`）列出条目；输入 `/知识库 奥运五环` 查看内容。也可以直接说：

```text
用turtle画一个奥运五环，生成py文件给我
画一个奥运五坏
用matplotlib画奥运五环
奧運五環是什麼樣子
```

绘图请求自动保存为 `.py`；知识问答只回答问题。奥运五环采用课堂用近似几何参数，包含上蓝黑红、下黄绿、空心等大、局部交错遮挡，并附带 turtle 算法示例供模型参考；这些参数不是官方商标制图规范。示例不会被宿主自动执行，仍由模型生成、复核后保存。条目中的来源链接是查阅出处，程序不会访问它们。

## 扩充

在此目录新建 UTF-8 编码的 `my_topics.json`，顶层必须是数组：

```json
[
  {
    "title": "等边三角形",
    "kind": "drawing",
    "filename": "equilateral_triangle.py",
    "keywords": ["等边三角形", "等邊三角形"],
    "content": "三边相等，每个内角60度；用turtle画轮廓时每画一条边后转120度，重复3次。"
  }
]
```

- `title`、`keywords`、`content` 必填。关键词精确匹配，中文支持包含匹配，英文忽略大小写并匹配单词边界。简繁体、别名和常见笔误需要逐个加入，不会自动理解所有同义词。
- `kind: "drawing"` 用于可直接生成代码的绘图对象；库用法可写 `library`，其他知识可省略此字段。
- `filename` 可省略；填写时使用不带目录的英文 `.py` 名称，避免 `turtle.py`、`numpy.py` 等库名。
- `source` 可选，写来源及适用条件。内容应是可核对的事实，不包含密码、个人数据或改变助手行为的命令。
- 每条内容最长 1800 字符，每文件最多 128 KiB，最多读取按文件名排序的前 32 个 JSON。损坏、超限的文件或条目会提示并跳过。大段教材请拆成短条目。

每次提问重新读取，修改后无需重启；一次生成中的知识保持一致。没有匹配时仍由原模型回答，不代表知识已查证。静态检查及模型复核不能保证所有绘图和算法都正确，重要题目仍应实际查看输出。
